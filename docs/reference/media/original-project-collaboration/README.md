# Packaged original-project collaboration inspection

All content is synthetic. The candidate uses the packaged Chat frontend and
its real local HTTP, source, binding, FIFO, revision and result owners. Only
provider identity observations and model transport are scripted.

The primary question is “Which source may enter this original conversation,
and what actually happened to its requests?” The default view separates
received requests from explicit source grants. Details reveal the full brief,
constraints, inputs, decision and conclusions. Desktop inspection includes
queued, running, failed and returned requests together; narrow inspection
retains a long expanded purpose and context in the dialog's scroll region.
The 390-pixel viewport has no horizontal overflow.

The unavailable case closes only the synthetic original Session through its
store owner, then rereads the panel and revokes its retained grant in the UI.
The background Goal sidebar's status error is a separate fixture limitation:
the lifecycle-only source profile does not qualify generic portfolio status.
These views do not certify that sidebar, installed App/provider delivery,
natural model adoption or model quality.
