# Packaged original-project collaboration inspection

All content is synthetic. The candidate uses the packaged Chat frontend and
its real local HTTP, source, binding, FIFO, revision and result owners. Only
provider identity observations and model transport are scripted.

The primary question is “Which source may enter this original conversation,
and what actually happened to its requests?” The default view separates
received requests from explicit source grants. Details reveal the full brief,
constraints, inputs, decision and conclusions. Desktop inspection includes
queued, running, failed and returned requests together; narrow inspection
retains a long expanded purpose and context in the dialog's scroll region.
The 390-pixel viewport has no horizontal overflow.

- [Before: original header without the collaboration action](before-desktop.png),
  built from the baseline frontend.
- [After: mixed request states and explicit grant](after-desktop.png).
- [After: expanded long content at narrow width](after-narrow.png).
- [Unavailable: retained grant can still be revoked](unavailable-desktop.png).

The unavailable case closes only the synthetic original Session through its
store owner, then rereads the panel and revokes its retained grant in the UI.
The background Goal sidebar's status error is a separate fixture limitation:
the lifecycle-only source profile does not qualify generic portfolio status.
These views do not certify that sidebar, installed App/provider delivery,
natural model adoption or model quality.

## Corrections after an answer

The same synthetic SQLite/HTTP/FIFO fixture first completes and reads an
original answer, then accepts corrected source material. The old frontend
labels that current request as already read; the updated frontend selects only
the current revision's result and queue state.

- [Before: historical read presented as the current state](correction-before.png)
  (1440-pixel desktop, previous frontend).
- [After: the correction is queued in the original conversation](correction-after.png)
  (1200-pixel desktop, updated frontend).
- [Expanded corrected request at 390 pixels](correction-narrow.png), with 16px
  prose and no horizontal overflow.
- [Current and historical conclusions after execution](correction-result.png)
  (1440-pixel desktop). The existing disclosure retains both revisions.

The current request and independent result stay separate from the explicit
source grant. Escape closes the reader and returns focus to its original
collaboration button. Expanded content uses the existing scrolling region;
the long brief remains complete. Model transport is scripted, and the
background portfolio/proposal read failures are retained fixture limitations.
