# Product

This area describes the product LoopX is becoming. It separates durable
foundations from runtime-specific experiences, operator surfaces, use cases,
and staged roadmaps so experimental observations do not masquerade as stable
contracts.

## Current Product Truth

- [Product vision](vision.md): long-running Loop Agents, maintainer-first
  management, evidence, and open-source direction.
- [Core control-plane graphs](core-control-plane/README.md): the product and
  runtime map for state, interactions, and bounded contexts.
- [Steward monitoring](periodic-reports.md): native identity preparation,
  opt-in status checks, and the remaining work for scheduled portfolio reports.
- [Release readiness](release-readiness.md): the currently supported v0.x
  install and compatibility boundary.
- [Release note template](release-note-template.md): the copy-ready release
  decision summary, product groups, optional-capability guidance, validation,
  and bilingual attribution format.
- [Public adoption loop](public-adoption-loop.md): a public-safe path from
  external attempt to inspectable feedback.
- [Domain capability packs](domain-capability-packs.md): what belongs in the
  generic control plane and what requires an explicit domain pack.
- [Scenario capability gap map](scenario-capability-gap-map.md): reusable
  capability increments across issue-fix and other scenario signals.

## Product Areas

- [Foundations](foundations/README.md): agent identity, planning, reward,
  replanning, and server/client shape.
- [Runtimes](runtimes/README.md): Codex CLI, Codex App, and future runtime
  experiences.
- [Operator surfaces](surfaces/README.md): status, observability, frontstage,
  and presentation boundaries.
- [Use cases](use-cases/README.md): auto research, issue/PR work,
  cross-runtime review, and office operations.
- [Roadmaps](roadmaps/README.md): proposed milestones that are not current
  runtime contracts.
- [Migrations and history](migrations/README.md): naming and state migrations.
