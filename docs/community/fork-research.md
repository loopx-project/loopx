# Fork contribution research

Checked **October 8, 2026**. This record helps contributors choose useful upstream work; it is not a merge queue, endorsement or adoption count. The [ecosystem inventory](ecosystem-adoption.md) separately records downstream use and derivative projects.

## Scope and method

The public GitHub fork endpoint returned 602 distinct repository records during the crawl. Git branch discovery succeeded for 596; six repositories returned not found. The upstream API reported 596 forks at that observation. These are repository observations, not independently active users or deployments.

The readable repositories exposed 43,033 branch references and 3,344 distinct tips. Comparing them with upstream's current branches, all exposed upstream PR heads and their reachable history reduced the unresolved set to 771 tips across 101 repositories. **Unresolved does not mean novel:** cherry-picks, discarded PR heads and copied branches can still be semantically equivalent. The upstream comparison covered 6,073 refs and 21,734 reachable commits. The initial metadata-only GraphQL attempt had partial batches and was replaced by complete Git branch discovery; it is not used as evidence of full branch coverage.

Discovery was pinned to [`d605f73720c48c5f9bc4cbb5bd669352e7dcc709`](https://github.com/loopx-project/loopx/commit/d605f73720c48c5f9bc4cbb5bd669352e7dcc709). The concrete source comparisons below also checked [`b6e0e53a81840059026ace3ef099f546901e2dfe`](https://github.com/loopx-project/loopx/commit/b6e0e53a81840059026ace3ef099f546901e2dfe). This is a dated checkpoint, not a claim that a moving branch stays unchanged.

PR lists were read for 12 targeted forks: ApexAiOfficial, Schofi, luning2024, xiaods, liangsalt, elegracer, bmshin94, Sande33p, yanfeng98, lightencc, manoelcalixto and douyipu. Branches without a fork-local PR were assessed as branches, not invented PRs. Known derivatives outside the fork network were checked against the existing inventory and prior contribution conversations. Deep review prioritised concrete current defects and reusable seams; every unresolved branch was not individually reviewed or executed.

## Continuing the research

Before selecting a candidate again, read its current exact head, upstream equivalent implementation, author conversation and licence at the selected revision. A useful contribution should name the current defect or missing outcome, reuse its nearest owner, and include a regression through the real caller. Record source-only inspection, author-reported tests, independent reproduction, actual upstream PR and merge separately. Recheck current Windows/HPC environments only when a concrete proposal requires them; this inventory did not run fork schedulers, install providers or publish websites.
