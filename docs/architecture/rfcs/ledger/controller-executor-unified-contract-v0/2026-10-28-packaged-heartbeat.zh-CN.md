## 主线集成与不可变 reader 身份

在 main `447c35ed6` 与 `ccf6aacc5` 上采用共享渐进材料 planner、通用 capture
selector、request-scoped settlement 与当前请求授权，未新增第二套决策或 schema。

- **Reader 边界修复（`5a770d183`）：** `context-read --select` 接续通过既有 CLI
  校验携带 selection digest；历史 replan 命令在展开诊断引用前先绑定原 capture 完整
  输入，避免不可变原捕获拒绝合法命令。
- **进程级 lane fence（`82f93ab76a`）：** 将已发布输入安装收回 staged-capture
  owner，使执行锁完整包住真实 Turn executor，并满足既有 90 语句上限（修复此前 94
  语句 premerge 失败及 `fc4763098` 两项 busy-request 失败）。
- **数值保真与修改计划（`7f35454b39`、`fd65514e7`、`dd600ac02`）：** `1.0` 与 `1`、
  `-0.0` 及大整数拼写导致 `c335aae894` 上适配 `#7633` 出现 **10 项中 8 项** display／CLI
  反例及 **5 项中 4 项**完整组合失败，即使吸收 `#7643` 仍未消除。将稀疏数值拼写传给
  TypeScript `diagnostic_projection.ts` / `turn_envelope.ts` 并在原 Python IO 值上应用
  修改计划后，修复 15 项中 12 项失败（相同合同返回体 `31,469` / `87,469` / `279,469`
  → `1,243 B`；保留不同正文时调用方视图 `279,469 → 536,456 B`）。既有 JavaScript 哈希
  归一化不变，与不可变精确字节 capture 摘要分离。
- **中断与历史失败保留：** 37 模块在 `1,364` 通过 / `3` 失败处停止（`281910a95`
  恢复缺任务 contract error）；16 模块在 `843` 通过 / `3` 失败处停止；长临时 namespace
  在主干和候选均复现两项 `2,015` 字符 hook 恢复失败；早期 `28` 项 codec 夹具失败、
  `27` 条八文件遗留 mypy 错误及包重编记录均保留。

## 签名完整输入的材料分阶段

在 main `b47bbc6c9` 上，真实 native `complete_turn` 调用方在完整决策校验通过后
复用同一 outcome scope、渐进材料与精确记录 owner，不修改或重签 canonical capture。

- **顺序与不变式：** 先 scope 后材料编辑，并保持原数组位置，避免筛选位置污染原证据
  指针；编辑前在 Python IO 侧区分整数浮点与整数；未知字段、不支持义务与小材料保持
  完整回退；关闭交付时行为不变。
- **当前捕获恢复（`#7628`）：** native 展示在可选材料规划前先发布当前原来源恢复与
  pending delivery（journal 发布由 `2` 增至 `3`），避免退出或压缩后回退到过期前驱。
- **Hook 与生命周期边界：** 用例区分完整 required-view 覆盖、未完成前缀与截断内层
  page（部分读取永不建立完整 baseline）；`outcome_context_projection_v0` 仅作可选
  分阶段载体；未提高或放宽任何预算门槛。

## 通过、失败与待验收门禁

- **通过（确定性源码与隔离 wheel 检查）：** 原 capture 读回、24 条要求完整性、保真
  引用共享、篡改／提前扣额拒绝、一次结算重放与进程级 lane fence（各检查点对应
  `144`–`333` 项 Python、`104`–`163` 项 TypeScript 及 `1,885`–`1,889` 个一致 wheel 成员）。
- **失败／负结果（未改判）：** v4 多 Agent 预算（`25,862 > 13,000`）、普通温态增约
  `2.8 KB` 与全部 peer 补读（`+10` 次调用）、延后共享原型请求膨胀（`8K`–`256K` 请求由
  `30.5K→55.2K` 至 `278.5K→1,047.2K`），以及长 namespace 下 `2,015` 字符恢复失败。
- **未验证／开放门禁：** 正式 App／模型保留、真实 tokens/cache/账单、受控延迟、原生
  Windows 执行、RFC §9 匹配单会话成果与完整成本对照、剩余消费者／writer 切换及历史
  reader 退役。
