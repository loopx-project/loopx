# 宿主 provider 复用检查点

[English mirror](2026-10-11-host-provider-reuse.md)

既有 provider-neutral 合同已用于一个真实宿主调研 method，以及一个读取公开源码的
宿主管理 GitHub connector。method 复用 gh、公开 Jina Reader 请求和经 mcporter
调用的匿名 Exa MCP 搜索；connector 读取了固定 commit 的 Browser Harness README。
没有新增爬虫、provider 协议、账户配置或研究 authority。

两条成功路径均返回 exact-plan receipt，并经过独立父 Agent admission。method 的
四条来源和 connector 的一条来源以匹配 lineage 投影到既有 deepresearch 账本；原生
读回没有写入 blocker，且满足退休条件。另一次浏览器来源 connector 调用返回
`source_content_not_ready`；失败回执来源为空，经明确拒绝后满足退休条件，没有证据
投影，也没有用此前成功 probe 的正文替代这次失败。

这些是 caller 声明的观察，不是执行认证。本次有界结果验证了这些操作复用既有 CLI
provenance 流程；未验收私有仓库权限、所有浏览器 URL、付费搜索容量、带认证的 Exa
Agent、真实 frontend/Lark 送达或整体研究完整性。X 召回主要为推广贴，未采纳其技术
断言。

可复用操作路径见
[capability guide](../../../../../loopx/capabilities/external_research/README.md#host-methods-and-connectors--宿主方法与-connector)。
原始观察与宿主身份保留私有。下一步由既有 provider/产品入口 owner 验证有界的撤权、
失败、恢复与真实下游展示，无需另建通用 executor。
