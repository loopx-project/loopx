## 交付边界

现有 Turn-envelope dispatcher 调用 TypeScript 记忆选择器。
Python 私有 IO 适配器复用只写一次的 capture、精确 reader 和原生 journal 锁，
在普通生命周期处理之后运行。Pre/PostCompact 对同一来源/视图去重；
SessionStart(compact) 验证后增量恢复。原生生命周期、Progressive/Delta 选择、
原来源字节与待完成读取继续由原 owner 管理。新版本化 schema 是派生上下文数据；
注册的机器命名空间扩展配置，不扩展工作权威。不增加 capability/provider id 或语义生成服务。

工作台通过现有配置 preview/apply/readback 提供独立、默认关闭的本机开关。
关闭会移除命名空间以支持旧版全量设置编辑器，并保留不可变引用。
操作参考使用规范的桌面关闭/开启与窄屏指南图片；执行日志和其他生成截图不进入 Git。

## 验证与限制

- 纯 TypeScript 测试保留精确的失败/未验证区分、长事实仅引用、来源/作用域版本，
  以及匹配的 canonical Todo 详情。
- 私有 capture 与真实 hook CLI 测试覆盖重复 hook、精确 reader 展开、journal/来源不变、
  未设置/关闭和 context-delivery 关闭、不支持 profile、子/异会话、损坏 locator、
  来源变化/缺失、不安全权限及 symlink 拒绝。已有配置/API 清单测试包含独立机器命名空间。
- 真实原生 `0.167.0-alpha.3.2` app-server 使用隔离 home 与合成 loopback 推理。
  两个测试（关闭/开启）触发自动压缩，检查全部四次实际模型提交。
  开启后恢复输入包含完整短 JSON 结构和精确的负面/未完成注记；关闭保留普通行为。
  原生 managed policy 保持生效；仅精确测试 hook 获得夹具信任。
  这仅覆盖一个宿主/版本、每组一次压缩，不是任务效果实验或已安装用户环境验收。
- 打包工作台浏览器 smoke 使用真实 Chat 后端与隔离空 registry，检查开启、刷新保持、
  后端真实拒绝过期 CAS 请求、已确认状态不变、关闭/移除、中文读回，以及保存不派发工作。
  桌面 1440×1000 与窄屏 430×932 均保留开关、无页面横向溢出。
  已填充能力列表包含其他机器和混合作用域项；不使用真实 Goal 或用户数据。
  窄屏现有选择器占据编辑器上方空间；首屏仍能看到设置。

## 有界机制成本

一个合成 Todo 加 400 次重复支持句，原始 capture 为 18,205 字节，记忆产物为 844 字节。
同来源准备 7 次耗时 7.48–11.52 ms（中位 7.81 ms）；一次恢复为 6.96 ms。
普通恢复为 3,169 字节；记忆增加 1,297 字节。不增加模型调用。
这些是包含本地生成引用的局部机制测量，不代表真实工作负载、token 数、延迟分布或完整成本收益。
恢复仍为增量追加。
