# Protected literal context in the Research reader

These public synthetic viewports use the packaged production reader, actual
SQLite/Explore history, verified input pack and local analysis-job/HTTP owners.
The twenty-hour fixture contains twenty questions and ten tentative/refuted
findings. Its provider is a deterministic synthetic process, not a model-quality
or installed-App acceptance run. The PR records the tested revision.

`first-*` preserves the existing default hierarchy. `reader-*` reads the Chinese
negative finding, failed-check meaning and preliminary local scope while keeping
literal run notes and a negative measurement exact. `original-reader-*` returns
the same selected content to English. These are two modes of the same build,
not a fabricated prior implementation. At narrow width the capture starts at
the reading region's beginning so both question and observation can be inspected.

The focused change supplies protected source terms as model context; it changes
no reader styles or navigation. The existing original switch stays in the reading
context; technical source/history details remain folded. Chinese meaning is in
the body, with exact source terms in parentheses. The narrow default still spends
substantial vertical space on the metric grid; this capture does not qualify a
broader page-density redesign. Complete body and original-reading screenshots
are reviewed separately from integration and overflow assertions.

The existing scenario checks both languages, return focus, all historical rows,
partial/invalid coverage, source isolation, failed explicit retry and original
source bytes. No private Goal, transcript, machine path, account or credential
appears here. PNGs contain only IHDR, IDAT and IEND chunks.
